# Comptes et rôles

| Rôle     | Peut                                                                 |
| -------- | -------------------------------------------------------------------- |
| `viewer` | Tout consulter (groupes, hosts, checks, incidents).                  |
| `tech`   | Créer/modifier groupes, hosts, checks ; acquitter les incidents.     |
| `admin`  | Tout, plus suppression, canaux d'alerte et gestion des utilisateurs. |

Menu **Utilisateurs** (admin) : créer un compte (mot de passe fort exigé, e-mail pré-vérifié), changer un rôle, supprimer. Vous ne pouvez ni modifier ni supprimer votre propre compte. Chaque utilisateur peut activer la 2FA ou une passkey dans **Réglages > Sécurité**.
