# Accounts and roles

| Role     | Can do                                                                        |
| -------- | ----------------------------------------------------------------------------- |
| `viewer` | View everything (groups, servers, checks, incidents).                         |
| `tech`   | Create and edit groups, servers, checks; acknowledge incidents.               |
| `admin`  | Everything above, plus delete resources, alert channels, and user management. |

**Users** menu (admin): create an account (strong password required, email pre-verified), change roles, delete users. You cannot edit or delete your own account.

Each user can enable **two-factor authentication** or a **passkey** under **Settings → Security**.
